# PipeForge：AIを活用したパイプ曲げ・生産技術の検討（日本語の概要）

> この日本語は、日本語を学習中の私が作成した要約です。流暢であることを示すものではありません。正確な内容は英語版の [README.md](README.md) をご覧ください。

## 目的

やまと興業株式会社（浜松）の技術職への応募にあたり、二輪・四輪用の曲げパイプを題材として、次の業務を自分で手を動かして学ぶための検討です。
- CAD
- 図面
- 製造性
- 治具
- 自動化
- ライン立ち上げ
- 改善

## 内容

| 項目 | 内容 |
|---|---|
| 3D CAD・図面 | CadQuery による曲げパイプの 3D モデル（STEP/STL）。第三角法の A3 図面（曲げ表・表題欄付き） |
| 曲げプログラム | XYZ 点列 → LRA（公称）→ YBC（スプリングバック補正済み）。曲げ戻り後の半径増加による送り長さも補正 |
| 製造性チェック | 曲げ半径比（D）、ウォールファクター、マンドレル・ワイパー選定表、クランプ長、曲げ間直線長、曲げ順序の干渉シミュレーション、必要伸び（JIS） |
| スプリングバック予測 | TubeBEND（実曲げ 318 本、CC BY 4.0）で学習。未知の設定に対する平均絶対誤差 0.050°（GroupKFold）。教科書的な計算式は 0.35°、実測は 2.60° |
| 検査治具 | 溝付きブロック、3-2-1 の基準（データム）、3D プリント可能なブロック |
| 自動検査ステーション | PLC 風のシーケンス（状態遷移）、ポカヨケのインターロック、I/O 一覧 |
| ライン・改善 | 切断 → 端末加工 → 曲げ → TIG 溶接 → 検査 → 梱包。タクトタイム、OEE、山積み表。ライン編成替え・段取り替え改善（SMED）・バッファ・スプリングバック補正で、合成ライン上の良品数 940 → 1,396 個/日 |
| 工程表 | 工程・設備・管理項目・規格・検査方法・頻度・記録・異常処置（Excel / PDF） |

## 正直に書いておくこと

- **工場での実績はありません。** 自主的な検討であり、工場への導入実績、ラインでの検証、顧客での使用はありません。
- **合成データ：** サンプル部品の形状とラインの条件。
- **実データ：** スプリングバックのデータ（TubeBEND、出典を明記）。
- **推定値：** 物理モデル（スプリングバック・肉厚減少・偏平）の値は工学的な推定値で、出典と前提を [docs/ENGINEERING_NOTES.md](docs/ENGINEERING_NOTES.md) に記載しています。
